# PRD — Лендинг стоматологической клиники «BrightSmile Dental»

## 1. Цель продукта

Продающий одностраничный сайт стоматологической клиники, который:
- за 5–10 секунд объясняет, чем клиника лучше других;
- снимает страхи пациента (боль, цена, доверие к врачам);
- приводит посетителя к **заявке на приём** — главная метрика сайта.

## 2. Целевая аудитория

| Сегмент | Что важно |
|---|---|
| Взрослые 25–45 лет | Скорость записи, прозрачные цены, удобное время |
| Родители с детьми | Детский врач, безболезненность, отзывы |
| Люди 45+ | Имплантация, протезирование, опыт врачей, рассрочка |
| Англоязычные пациенты (EN) | Понятные цены, английский язык, контакты |

## 3. Языки

- Русский (по умолчанию) и английский.
- Переключатель языка в шапке, у каждого языка свой URL: `/ru`, `/en`.
- Английская версия пишется как самостоятельный текст для англоязычного читателя, а не как дословный перевод.

## 4. Структура страницы (секции по порядку)

### 4.1 Шапка (Header)
- Логотип, навигация по секциям (якоря), переключатель языка, телефон, кнопка «Записаться».
- Липкая (sticky) при прокрутке, на мобильных — бургер-меню.

### 4.2 Hero (первый экран)
- Заголовок с главным обещанием (пример: «Лечение зубов без боли и страха»).
- Подзаголовок, кнопка «Записаться на бесплатную консультацию», вторичная кнопка «Смотреть цены».
- Блок доверия: лет работы, число пациентов, рейтинг, гарантия.
- Фото улыбающегося пациента / врача.

### 4.3 Преимущества
- 4–6 карточек с иконками: безболезненное лечение, современное оборудование, гарантия до N лет, рассрочка, детский врач, работаем без выходных.

### 4.4 Услуги и цены
- Категории во вкладках: Терапия, Гигиена, Имплантация, Ортодонтия, Эстетика (отбеливание, виниры), Детская стоматология.
- У каждой услуги: название, короткое описание, цена «от … ₽».
- Кнопка «Записаться» у каждой услуги — переносит к форме с уже выбранной услугой.
- Под списком — примечание: точная стоимость определяется после консультации.

### 4.5 До / После
- Галерея работ с интерактивным слайдером сравнения (перетаскиваемый разделитель «до/после»).
- 4–6 кейсов с подписью: услуга, срок лечения.

### 4.6 Врачи
- Карточки: фото, имя, специализация, стаж, кнопка «Записаться к врачу» (форма с выбранным врачом).

### 4.7 Как проходит приём
- 4 шага: заявка → звонок администратора → консультация и план лечения → лечение.

### 4.8 Акция / оффер
- Яркий блок: «Бесплатная консультация и 3D-снимок при записи через сайт» + кнопка.

### 4.9 Отзывы
- Карусель отзывов: имя, оценка (звёзды), текст, услуга.

### 4.10 FAQ
- Аккордеон, 6–8 вопросов: больно ли, сколько стоит, есть ли рассрочка, гарантия, лечение детей, как подготовиться.

### 4.11 Форма записи
- Поля: имя*, телефон* (в международном формате, с выбором страны), услуга (выбор), врач (выбор), желаемая дата, удобное время (утро / день / вечер), комментарий, согласие на обработку данных* (со ссылкой на политику конфиденциальности).
- После отправки — сообщение об успехе. Заявка мгновенно приходит в Telegram администратора.

### 4.12 Контакты
- Адрес, телефон, email, часы работы, ссылки на Telegram / Instagram, карта.

### 4.13 Футер
- Логотип, краткая навигация, контакты, копирайт, ссылка на политику конфиденциальности.

### 4.14 Плавающие элементы
- Кнопка Telegram в углу экрана.
- На мобильных — закреплённая снизу кнопка «Записаться».

### 4.15 Дополнительные страницы
- Политика конфиденциальности (`/[locale]/privacy`).
- Страница 404 в стиле сайта, с кнопкой «На главную».

## 6. Нефункциональные требования

- **Адаптивность:** корректно от 360 px до 1920 px, mobile-first.
- **Скорость:** Lighthouse Performance ≥ 90 на мобильных; оптимизированные изображения.
- **SEO:** мета-теги и Open Graph на каждом языке, `hreflang`, sitemap, robots.txt, микроразметка Schema.org `Dentist`.
- **Доступность:** контраст, alt у изображений, работа с клавиатуры, Lighthouse Accessibility ≥ 90.
- **Безопасность:** секретные ключи только на сервере; пользовательский ввод экранируется.
- **Дизайн:** чистый, «медицинский», но тёплый; светлый фон, бирюзово-мятный акцент.
- **Тексты:** весь контент сайта, кода и README написан как для действующей клиники — без пометок «демо», «пример», «тестовый проект» или «портфолио».
- **Тон текстов:** дружелюбный, спокойный, уверенный. Без медицинских обещаний, которые нельзя гарантировать («100% без боли», «навсегда»), без давления и капслока.

## 7. Вне рамок проекта (НЕ делаем)

- Онлайн-расписание с реальными свободными слотами.
- Личный кабинет пациента, авторизация.
- Онлайн-оплата.
- Админ-панель и база данных (контент хранится в файлах проекта).
- Блог.
- AI-чатбот.
- Веб-аналитика и cookie-баннер.

## 8. Критерии готовности

- Все секции из раздела 4 сверстаны на двух языках.
- Тестовая заявка с телефона приходит в Telegram за ≤ 5 секунд.
- Lighthouse (мобильный): Performance ≥ 90, Accessibility ≥ 90, SEO ≥ 95.
- `npm run build` и `npm run lint` проходят без ошибок.
- Сайт задеплоен и открывается по публичной ссылке.
- Есть README с описанием проекта, стеком и инструкцией по запуску.
