# Фотографии и видео сайта

Все файлы лежат в `public/`. Код ссылается на них по имени, поэтому, чтобы заменить фото или видео, достаточно положить новый файл с тем же именем. Промпты для генерации — в [PHOTO-PROMPTS.md](PHOTO-PROMPTS.md).

Пока файла нет, на его месте показывается светлый блок-заглушка тех же пропорций (компонент `Photo` → `ImagePlaceholder`), вёрстка не ломается.

## Общие требования

- Фото: WebP, качество 80–85, sRGB, не меньше указанного размера, в тех же пропорциях.
- Видео: без звука, 8–12 секунд, два формата — `.webm` (VP9) и `.mp4` (H.264, `+faststart`). Браузер сам выберет WebM, MP4 — запасной вариант.
- Стиль: дневной свет, белые стены, светлый дуб, голубые акценты, форма врачей голубая или белая. Без текста и логотипов.
- На всех фото с людьми нужно письменное согласие на публикацию. Сгенерированные фото врачей и «до/после» перед запуском нужно заменить реальными (см. README, чек-лист).

| `videos/tour.webm`, `.mp4` | Блок «Консультация и 3D-снимок бесплатно», в рамке 16:9 | 1280×720, около 0,6 МБ | Проход по клинике: ресепшен, коридор, кабинет. |

Как работает воспроизведение (`src/components/ui/AutoplayVideo.tsx`):
- видео начинает грузиться, только когда блок появляется на экране, и ставится на паузу, когда уходит;
- до загрузки и тем, у кого включено «уменьшить движение» или экономия трафика, показывается обложка (`hero.webp`, `tour.webp`);
- звука нет, кнопок управления нет.

## Как заменить файл

1. Положите исходник (JPG/PNG из генератора или MP4) в `photos-raw/`. Эта папка не попадает в git.
2. Приведите к размеру и формату из таблицы. Видео сжимается так (пример для первого экрана):
   ```
   ffmpeg -i source.mp4 -an -c:v libvpx-vp9 -b:v 0 -crf 38 -row-mt 1 public/videos/hero.webm
   ffmpeg -i source.mp4 -an -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -movflags +faststart public/videos/hero.mp4
   ffmpeg -i source.mp4 -an -vf scale=1280:720 -c:v libvpx-vp9 -b:v 0 -crf 40 -row-mt 1 public/videos/hero-mobile.webm
   ffmpeg -i source.mp4 -an -vf scale=1280:720 -c:v libx264 -preset slow -crf 28 -pix_fmt yuv420p -movflags +faststart public/videos/hero-mobile.mp4
   ffmpeg -i source.mp4 -vf "select=eq(n\,0)" -frames:v 1 poster.png   # затем в WebP → public/images/hero.webp
   ```
3. Если файл заменён под **тем же именем**, а сайт показывает старое фото, удалите кеш картинок Next.js (`.next/dev/cache/images` и `.next/cache/images`), перезапустите сервер и обновите страницу с очисткой кеша (Ctrl+F5).
