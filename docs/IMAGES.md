# Фотографии сайта

Пока файла нет, на его месте показывается аккуратный блок в цветах сайта тех же пропорций (компонент `Photo` → `ImagePlaceholder`). Чтобы поставить настоящее фото, достаточно положить файл с указанным именем в `public/` — код менять не нужно, изменения подхватятся при следующей сборке.

**Общие требования:** формат WebP, качество 80–85, цветовой профиль sRGB. Размер — не меньше указанного (можно больше в тех же пропорциях). Тёплый естественный свет, светлый фон, без стоковой «пластиковости». На всех фото с людьми нужно письменное согласие на публикацию.
