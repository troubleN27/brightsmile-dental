# BrightSmile Dental

Сайт стоматологической клиники BrightSmile Dental в Москве. Одностраничный лендинг на русском и английском (для англоязычных пациентов): услуги с ценами, результаты «до/после», врачи, отзывы, ответы на частые вопросы и онлайн-запись на приём, которая мгновенно приходит администратору в Telegram.

## Возможности

- Два языка с отдельными адресами `/ru` и `/en`; с `/` посетитель попадает на язык браузера.
- Услуги и цены во вкладках, слайдер сравнения «до/после», карусель отзывов, FAQ-аккордеон.
- Форма записи с проверкой международного номера телефона; кнопки «Записаться» у услуг и врачей сразу подставляют выбор в форму.
- Заявки уходят в Telegram администратора; защита от спама — скрытое поле-ловушка и ограничение частоты.
- Плавающая кнопка Telegram, на телефонах — закреплённая кнопка записи.
- SEO: мета-теги и Open Graph на каждом языке, `hreflang`, sitemap, robots.txt, микроразметка Schema.org `Dentist`, автоматическая картинка для превью ссылок.
- Доступность: работа с клавиатуры, корректная семантика, уважение настройки «уменьшить движение».
- Политика конфиденциальности и страница 404 на обоих языках.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
cp .env.example .env.local   # заполните значения, см. ниже
npm run dev                  # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер разработки |
| `npm run build` | Продакшен-сборка |
| `npm run start` | Запуск собранного сайта |
| `npm run lint` | Проверка кода ESLint |

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | Токен Telegram-бота, который присылает заявки. Используется только на сервере |
| `TELEGRAM_CHAT_ID` | да | Чат администратора, куда приходят заявки |
| `NEXT_PUBLIC_SITE_URL` | рекомендуется | Адрес сайта, например `https://brightsmile.dental`. Нужен для canonical, sitemap и превью ссылок. Если не задан, на Vercel берётся продакшен-домен проекта (`VERCEL_PROJECT_PRODUCTION_URL`), локально — `http://localhost:3000` |
| `TELEGRAM_API_URL` | нет | Только для локальной проверки с заглушкой Telegram API. В продакшене не задавайте |

Если токен или чат не заданы, сайт работает, а `POST /api/booking` отвечает `500` и пишет в лог сервера, какой переменной не хватает.

## Заявки в Telegram

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя — получите токен бота.
2. Напишите своему боту любое сообщение (или добавьте его в рабочую группу администраторов и напишите там).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}` — это `TELEGRAM_CHAT_ID` (у групп он начинается с `-`).
4. Впишите оба значения в `.env.local` и перезапустите `npm run dev`.
5. Отправьте тестовую заявку с сайта — сообщение придёт в чат за пару секунд.

Защита формы: скрытое поле-ловушка для ботов и не больше 3 заявок с одного IP за 10 минут. Счётчик хранится в памяти сервера, поэтому на Vercel у каждого экземпляра он свой; для строгого лимита при росте нагрузки перенесите его в Redis/Upstash (`src/lib/rate-limit.ts`).

## Деплой на Vercel

1. Загрузите репозиторий на GitHub (приватный).
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий. Настройки сборки определятся автоматически (Next.js).
3. В **Settings → Environment Variables** добавьте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `NEXT_PUBLIC_SITE_URL` для окружения Production.
4. Нажмите **Deploy**. После публикации отправьте тестовую заявку с телефона и проверьте, что она пришла в Telegram.
5. Свой домен подключается в **Settings → Domains**; после этого обновите `NEXT_PUBLIC_SITE_URL` и сделайте повторный деплой.

## Перед запуском

- Замените в `src/config/site.ts` телефон, адрес, ближайшее метро, координаты карты, ссылки на Telegram и Instagram, статистику и `reviewCount` на реальные данные.
- Заполните в `site.legal` реквизиты: юрлицо, ИНН, ОГРН и номер лицензии на медицинскую деятельность. Пустые поля на сайте не показываются, но для медицинской организации эти сведения обязательны.
- Персональные данные (152-ФЗ): подайте уведомление об обработке ПДн в Роскомнадзор. Сейчас заявки сразу уходят в Telegram и хостятся на Vercel — серверы за пределами РФ. Требование локализации (ч. 5 ст. 18 152-ФЗ) обязывает сначала записывать данные граждан РФ в базу на территории России, поэтому перед запуском стоит добавить сохранение заявок в российское хранилище (CRM или база) и обсудить схему с юристом.
- Фото и видео сейчас сгенерированы нейросетью (список и требования — в [docs/IMAGES.md](docs/IMAGES.md), промпты — в [docs/PHOTO-PROMPTS.md](docs/PHOTO-PROMPTS.md)). Портреты врачей и работы «до/после» замените реальными: файлы с теми же именами подхватятся без правок кода.
- Проверьте услуги, цены, врачей, кейсы и отзывы в `src/data/` — отзывы и кейсы должны быть настоящими и опубликованы с согласия пациентов.
- Покажите текст политики обработки персональных данных (`messages/*.json` → `Privacy`) и согласия в форме юристу; при изменении обновите дату в `src/app/[locale]/privacy/page.tsx`.

## Структура

```
messages/              тексты интерфейса (ru.json, en.json)
public/images/         фотографии (см. docs/IMAGES.md)
public/videos/         видео первого экрана и тура по клинике
src/app/[locale]/      страницы: главная, политика конфиденциальности, 404, превью для соцсетей
src/app/api/booking/   приём заявок и отправка в Telegram
src/app/sitemap.ts     карта сайта; robots.ts — правила для поисковиков
src/components/        layout (шапка, футер, меню), sections (секции лендинга), ui, seo
src/config/site.ts     контакты клиники, часы работы, статистика — в одном месте
src/data/              услуги, врачи, кейсы, отзывы, FAQ на двух языках
src/lib/               схема формы, Telegram, ограничение частоты, цены, SEO-хелперы
src/store/booking.tsx  выбранные услуга и врач для предзаполнения формы
src/proxy.ts           определение языка посетителя и редирект с «/»
docs/                  требования (PRD), спецификация (SPEC), список фотографий
```

Контакты клиники меняются в `src/config/site.ts`, тексты — в `messages/*.json`.
